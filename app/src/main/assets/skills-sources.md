# Provenance des skills inclus

Les fichiers des skills sont copiés sans réécriture depuis les versions suivantes. Les licences et avis associés sont conservés dans les dossiers des skills ou dans `third_party/` et dans les ressources de l’application.

- [anthropics/skills](https://github.com/anthropics/skills), commit `2c5958ecac7cee2b583967a2c4981d0f4a75c579` : `docx`, `pdf`, `pptx`, `xlsx`, `doc-coauthoring`, `theme-factory`, `frontend-design`, `webapp-testing` ; licence Apache 2.0. Les quatre skills bureautiques ont changé de licence dans ce commit : vérifier les licences dans chaque dossier et les avis tiers.
- [Sergio-CVM00/android-design-skills](https://github.com/Sergio-CVM00/android-design-skills), commit `e35acc3a730ccfc137ca12c9641af7882f0fa845` : les huit dossiers `android-ui-*` ; licence Apache 2.0, avis inclus.
- [moyx782/agent-development-skills](https://github.com/moyx782/agent-development-skills), commit `fe206c01e6ec9c6ff11742702430c403b13044f7` : `project-initialization` et `frontend-design-workflow` ; licence MIT.

Les skills sont des instructions et ressources tierces, pas des programmes exécutés automatiquement. Leurs scripts ou dépendances peuvent nécessiter un environnement distant compatible. Les skills installés ultérieurement par l’utilisateur ne sont pas audités automatiquement et leur licence doit être vérifiée à la source.
